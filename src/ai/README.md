# AI

Integração opcional com Inteligência Artificial. Contém a interface `NoteOrganizer` e o cliente que se comunica com a função serverless do backend.

**Regras:**

- Nenhuma chave de API fica no front-end.
- O app deve continuar 100% funcional caso esta camada falhe ou esteja offline.
